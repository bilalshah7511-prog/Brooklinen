# Brooklinen Checkout Skin Demo

PayPhi-style cart/checkout drawer skin for **Brooklinen** (Luxe Sateen Core Sheet Set).

## Stack
- React + Vite
- Brandon Text Bold
- Shared checkout flow: shipping / delivery / payment, drawer-scoped checkout loader, card brand logos

## Run
```bash
npm install
npm run dev
```

Promo code: `BROOKLINEN10`
